# FNP Sales Analysis Dashboard

## Project Overview

This project presents an interactive sales analysis dashboard created in Microsoft Excel using FNP sales data.
The dashboard transforms raw transactional data into meaningful business insights through KPIs, charts, and interactive filters.

## Dashboard Preview

[FNP Sales Analysis Dashboard](fnp-dashboard.png)

## Key Metrics

- Total Orders: 1,000
- Total Revenue: ₹35,20,984
- Average Customer Spend: ₹3,520.98
- Average Order-to-Delivery Time: 5.53

## Key Analysis

The dashboard provides insights into:

- Revenue by Occasion
- Revenue by Product Category
- Revenue by Order Hour
- Monthly Revenue Trends
- Top 5 Products by Revenue
- Top 10 Cities by Orders
- Order-to-Delivery Performance

## Key Insights

- Revenue varies significantly across different occasions.
- Colors is the highest-revenue product category in the dataset.
- Sales show noticeable seasonal variations across different months.
- Several products contribute significantly to overall revenue.
- Order volumes are distributed across multiple cities.
- Order timing and delivery performance provide additional opportunities for operational analysis.

## Project Objective

The objective of this project was to analyze FNP sales data and create an interactive dashboard that helps users understand sales performance and identify important trends across products, categories, occasions, time periods, and locations.

## Conclusion

This project demonstrates how Excel can be used to transform raw sales data into an interactive business intelligence dashboard and communicate data-driven insights effectively.
